Open files from the **File** tab with **Open** and **Browse…**. Save with **Save** or **Save As**. WordCraft saves .docx by default.

## Open a document

1. Click the **File** tab.
2. Click **Open**.
3. Click **Browse…** and choose a file. Or click a name under **Recent**.

The file picker offers these types: .docx, .docm, .dotx, .dotm, .doc, .dot, .odt, .rtf, .txt, .md, .html, .htm and .tex. WordCraft opens Word 97-2003 .doc files but does not save them. It saves a .docx instead.

If your current document has unsaved changes, WordCraft asks **Do you want to save changes to** the document first. Choose **Save**, **Don't Save** or **Cancel**.

## Save a document

1. Click the **File** tab.
2. Click **Save** to save under the current name. A new document has no name yet, so **Save** asks for one.
3. Click **Save As** to save under a different name or place. The suggested name ends in .docx unless the document was opened from another Word package type, such as .dotx, which keeps its own ending.

To save a copy as PDF or another format, see [Export to PDF and other formats](export-to-pdf.md).

## Add a title and author

1. Click the **File** tab, then **Info**.
2. Type in **Title**, **Subject**, **Author**, **Keywords** or **Category**. Changes go into the document as you type.

The same page shows the number of **Pages**, **Words**, **Paragraphs**, **Sections** and **Comments**, and where the file is saved.
